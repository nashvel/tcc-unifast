# Separate Vue Frontend from Laravel Backend

## Goal

Move the Vue SPA into a standalone `frontend/` package within the same monorepo, and switch from session-based auth to Laravel Sanctum token-based auth. The frontend and backend become independently buildable and deployable.

## Current Architecture

- Vue source lives in `resources/js/` (Laravel convention)
- Build uses `laravel-vite-plugin` with `@vite()` Blade directive
- Auth is session-based with CSRF tokens injected via `<meta>` tag in Blade
- All API routes use `web.php` middleware stack (session cookies)
- All fetch calls use relative URLs (`/api/...`) assuming same-origin
- Blade template injects locale data via `window.__APP_LOCALE__`
- SSR is scaffolded but minimal

## Key Changes

### 1. Backend: Laravel Sanctum

**Install:**
```bash
composer require laravel/sanctum
php artisan install:api
```

**Migrate API routes from `web.php` to `api.php`:**
- Move all `/api/*` routes from `routes/web.php` to `routes/api.php`
- Add `sanctum` middleware to the api group
- Remove the SPA catch-all route from `web.php`
- Keep `web.php` minimal (just a health check or admin panel if needed)

**Add CORS config** (`config/cors.php`):
```php
'allowed_origins' => ['http://localhost:5173', 'https://your-frontend-domain.com'],
'supports_credentials' => true,
```

**Modify AuthController:**
- Login returns a Sanctum token: `$user->createToken('auth-token')->plainTextToken`
- Logout revokes tokens: `$request->user()->currentAccessToken()->delete()`
- `/api/auth/me` uses token auth, not session auth

### 2. Frontend: Standalone Package

**Create `frontend/` directory with:**
- `package.json` — copy dependencies from root, add `vite`, `vue-tsc`, `typescript`
- `vite.config.ts` — plain Vite with `@` alias, no `laravel-vite-plugin`
- `tsconfig.json` — update paths to `./src/*`
- `index.html` — static SPA shell (replaces Blade template)

**Move source files:**
```
resources/js/*  →  frontend/src/
resources/css/  →  frontend/src/assets/
```

**Update `frontend/index.html`** (static SPA shell):
```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="theme-color" content="#4a141d">
  <title>UniFAST TES</title>
  <link rel="icon" href="/favicon.ico">
  <script type="module" src="/src/app.ts"></script>
</head>
<body>
  <div id="app"></div>
</body>
</html>
```

**Update `frontend/.env.example`:**
```
VITE_API_BASE_URL=http://localhost:8000
VITE_REVERB_APP_KEY=
VITE_REVERB_HOST=localhost
VITE_REVERB_PORT=8080
VITE_REVERB_SCHEME=http
```

### 3. Frontend: Auth Changes

**Replace CSRF token with Sanctum Bearer token:**

`frontend/src/auth/session.ts`:
```ts
// Store token in localStorage
const TOKEN_KEY = "unifast_auth_token";

export function getAuthToken(): string | null {
  return localStorage.getItem(TOKEN_KEY);
}

export function setAuthToken(token: string) {
  localStorage.setItem(TOKEN_KEY, token);
}

export function clearAuthToken() {
  localStorage.removeItem(TOKEN_KEY);
}
```

**Update `frontend/src/api/client.ts`:**
```ts
import { getAuthToken } from "@/auth/session";

// In apiFetch, replace CSRF header with Bearer token:
if (init.method && init.method !== "GET") {
  const token = getAuthToken();
  if (token) headers.set("Authorization", `Bearer ${token}`);
}
// Remove X-CSRF-TOKEN header logic
```

**Update `frontend/src/api/auth.ts`:**
```ts
export async function login(email: string, password: string) {
  const payload = await apiFetch<{ user: AuthUser; token: string }>(
    `${API_BASE}/api/auth/login`, {
      method: "POST",
      body: JSON.stringify({ email, password }),
    }
  );
  setAuthToken(payload.token);
  return payload.user;
}

export async function logout() {
  await apiFetch(`${API_BASE}/api/auth/logout`, { method: "POST" });
  clearAuthToken();
}
```

### 4. Frontend: Add API Base URL

**Create `frontend/src/config.ts`:**
```ts
export const API_BASE = import.meta.env.VITE_API_BASE_URL || "";
```

**Update all `api/*.ts` modules** to prepend `API_BASE`:
```ts
import { API_BASE } from "@/config";
// Change: apiFetch("/api/batches")
// To:     apiFetch(`${API_BASE}/api/batches`)
```

### 5. Frontend: Handle Locale Client-Side

**Replace `window.__APP_LOCALE__` with client-side logic:**

`frontend/src/i18n/routeLang.ts`:
- Read locale from `?lang=` query param (already does this)
- Default to `"en"` instead of reading from server-injected global
- Remove dependency on `window.__APP_LOCALE__`

### 6. Frontend: SEO Meta Tags

**Install `@vueuse/head`** and use `useHead()` in `createApp.ts`:
- Set `<title>` and `<meta>` tags client-side per route
- Remove dependency on Blade-injected SEO

### 7. Frontend: Broadcasting

**Update `composables/useEcho.ts`:**
- Use token auth for broadcast auth endpoint: `Authorization: Bearer <token>`
- Configure Reverb/Pusher connection via env vars

## Migration Steps

### Phase 1: Backend — Sanctum Setup
1. Install Laravel Sanctum
2. Run `php artisan install:api`
3. Create `PersonalAccessToken` migration (Sanctum does this)
4. Migrate API routes from `routes/web.php` to `routes/api.php`
5. Add `sanctum` middleware to API route group
6. Modify `AuthController` to return tokens on login
7. Configure CORS for frontend origin
8. Remove SPA catch-all from `web.php`

### Phase 2: Frontend — Standalone Package
9. Create `frontend/` directory
10. Create `frontend/package.json` (copy deps from root)
11. Create `frontend/vite.config.ts` (plain Vite)
12. Create `frontend/tsconfig.json`
13. Create `frontend/index.html` (static SPA shell)
14. Create `frontend/.env.example`
15. Move `resources/js/*` → `frontend/src/`
16. Move `resources/css/app.css` → `frontend/src/assets/app.css`
17. Update all `@` imports (should work as-is with alias)

### Phase 3: Frontend — Auth & Config Changes
18. Create `frontend/src/config.ts` (API_BASE)
19. Update `auth/session.ts` — add token storage functions
20. Update `api/client.ts` — Bearer token instead of CSRF
21. Update `api/auth.ts` — login returns token, logout revokes
22. Update all `api/*.ts` — prepend API_BASE to URLs
23. Update `composables/useEcho.ts` — token auth for broadcasting
24. Update `auth/Login.vue` — store token on login
25. Update `layouts/AppShell.vue` — clear token on logout

### Phase 4: Frontend — Remove Server Dependencies
26. Update `i18n/routeLang.ts` — remove `window.__APP_LOCALE__` dependency
27. Install `@vueuse/head` for client-side SEO
28. Update `createApp.ts` — add head management
29. Remove `ssr.ts` (SSR will be handled separately if needed)

### Phase 5: Cleanup
30. Update root `package.json` scripts (or remove if no longer needed)
31. Remove `resources/js/` and `resources/css/` from Laravel
32. Remove `laravel-vite-plugin` from root `package.json`
33. Update `.gitignore` for both packages
34. Update README with new dev/build instructions
