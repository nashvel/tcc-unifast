ANSI / ISO Standard Flowchart Architecture

UniFAST TES Grantee Management System

Figure 3.2: Modular Operational Lifecycle Flowchart — Structured into four (4) sequential phases using standard on-page circular connectors (A, B, C) to eliminate line clutter and clearly represent batch submission window enforcement.

💡
ANSI/ISO Flowchart Connector Convention Applied: Long looping arrow lines across pages have been eliminated. Each phase concludes with an on-page circular connector (e.g., 🟡 A), which serves as the direct entry point into the subsequent phase. Furthermore, Phase 3 now features the strict Batch Active & Submission Window Open decision gate preventing unauthorized document uploads.

🎤 Thesis Defense Speaking Points (Flowchart Justification)

1. Why use On-Page Connectors (A, B, C)? "To comply with ANSI/ISO Flowchart Standards and avoid spaghetti arrow routing, the system lifecycle is decomposed into 4 modular sequential phases using on-page circular connectors A, B, and C. This ensures modular readability and professional clarity."
2. Phase 1 to Phase 2 Transition (Connector A): "Phase 1 establishes batch creation and masterlist validation down to dispatching secure invitation links. At Connector A, the grantee accesses the onboarding portal to complete their student profile and upload their school ID without setting a password prematurely."
3. Biometric Verification & Facial Matching (Phase 2): "In Phase 2, the system extracts text and photo from the ID via OCR, then compares the student's live selfie against the ID photo using Biometric Facial Similarity Matching. If similarity is inconclusive, it routes to staff for manual verification before the account is activated at Connector B."
4. Batch Window Verification (Phase 3 Gate): "In Phase 3, immediately after Connector B, the system enforces a strict decision: 'Is Batch Active & Submission Window Open?'. If the window has expired or is inactive, upload is blocked with an informative notice, ensuring strict institutional compliance with CHED deadlines."
5. Academic Retention Evaluation (Connector C to Phase 4): "Once all 3 required documents pass automated OCR checks and staff evaluation, the system checks CHED retention standards (GWA and failed units limit) and assigns a compliance risk rating. Once confirmed ELIGIBLE, Connector C leads into Phase 4 for official CHED billing and fund payroll rosters."

Flowchart Legend & ANSI/ISO Symbol Standards

  • Admin Action: Batch setup, masterlist upload, billing generation.
  • Grantee Action: Portal activation, KYC data input, document upload.
  • Staff Action: Biometric side-by-side inspection, document validation queue.
  • System Process: Automated OCR, facial distance matching, notifications.
  • Decision Diamond: Validation gates, window checks, pass/fail branches.
  • On-Page Connector (Circle): Modular handoff between phases (A, B, C).
  • Data Store (Cylinder): Immutable system audit logs & database transactions.
