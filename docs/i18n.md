# Multilingual System

The application supports English (`en`), Tagalog (`tl`), and Bisaya/Cebuano (`ceb`) through the `lang` URL query parameter.

Examples:

- `/login?lang=en`
- `/student/documents?lang=tl`
- `/app/reports?lang=ceb`

Invalid languages fall back to English.

## Frontend

Locale files live in `resources/js/locales`. They are lazy-loaded by `resources/js/i18n/index.ts` and cached in memory after first use.

Use Vue I18n in components:

```ts
const { t } = useI18n();
t("common.hello", { name: "Richard" });
```

When adding links or programmatic navigation, prefer `withLang("/path")` from `@/i18n/routeLang` when the navigation code bypasses normal router links. The router guard also normalizes missing or invalid `lang` parameters.

## Backend

`SetLocaleFromUrl` reads `?lang=`, validates it, calls `app()->setLocale()`, and shares locale metadata with the Blade SPA shell.

## Adding a language

1. Add `resources/js/locales/xx.json`.
2. Register `xx` in `resources/js/i18n/types.ts`.
3. Add the language label to `languageLabels`.
4. Add the code to `SetLocaleFromUrl::SUPPORTED`.
